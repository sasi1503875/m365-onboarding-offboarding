# New Starter Onboarding Checklist

**Ticket #:** ______ **Start date:** ______ **Manager:** ______

## Before creating the account
- [ ] Request has been approved by the manager or HR (not just forwarded by the new starter)
- [ ] Full name, job title, department, start date and manager confirmed
- [ ] Check the user doesn't already exist (rehire or duplicate ticket)
- [ ] Licence type confirmed and a free licence is available
- [ ] Required groups / shared mailboxes / Teams / SharePoint sites listed by the manager

## Account setup (M365 Admin Center / Entra ID)
- [ ] User created with the correct UPN format (`firstname.lastname@domain`)
- [ ] Usage location set (required before a licence can be assigned)
- [ ] Licence assigned
- [ ] Job title, department and manager fields filled in (these drive dynamic groups and the org chart)
- [ ] Added to security groups and distribution lists
- [ ] Access to shared mailboxes granted (if requested)
- [ ] Temporary password set with "change at next sign-in" enabled

## Verify (allow ~15 minutes for provisioning)
- [ ] Mailbox shows in the Exchange admin center
- [ ] User appears in Teams and the right team channels
- [ ] OneDrive provisioned
- [ ] Device ready (see the Intune deployment project)

## Hand-over
- [ ] Credentials given to the manager by phone or a secure channel, **not** in the ticket or by plain email
- [ ] First sign-in arranged so the user can register MFA (see the MFA enrolment project)
- [ ] Welcome / "how to get IT help" KB article sent
- [ ] Ticket updated with what was done, then resolved
